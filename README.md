# Sun_Strategists
## 📖 About This Project

This is a **static demo website** built as a university project for a front-end development course.

It represents a fictional corporation called **Aftab Rahkaran** — a digital agency offering branding, SEO, and web design services. The goal was to practice building a professional-looking corporate landing page using only **HTML, CSS, and vanilla JavaScript**, with no frameworks or external libraries (except for icons and fonts).

> ⚠️ **Note:** This is a front-end prototype only. All links, forms, and interactions are visual demos and do not connect to a backend.

## 🎯 Purpose

- Demonstrate understanding of **semantic HTML5**
- Apply **CSS3** techniques: Flexbox, Grid, custom properties, transitions
- Use **vanilla JavaScript** for interactivity (navigation toggle, form validation, dynamic content)
- Practice **responsive design** (mobile-first approach)
- Create a clean, accessible, and visually appealing UI
